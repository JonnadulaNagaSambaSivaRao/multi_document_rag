\# LangChain Guide



LangChain is an open-source framework used to build applications powered by Large Language Models (LLMs).



\## Features



\- Prompt Templates

\- Chains

\- Memory

\- Retrieval

\- Agents



\## Vector Database



A vector database stores embeddings for semantic search.



\## RAG



Retrieval-Augmented Generation retrieves relevant documents before generating an answer.
